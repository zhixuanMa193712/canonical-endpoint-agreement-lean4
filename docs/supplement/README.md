## Supplementary Material Index

The supplement preserves protocol detail that is necessary for auditability but would interrupt the main argument. Internal experiment identifiers are retained only as immutable archive crosswalks; the manuscript organizes the evidence by scientific role.

- [Supplementary methods](supplementary_methods.md): archive lineage, the five realized root-local candidate panels and their 19-program intersection, frozen execution configuration, candidate genealogy, endpoint construction, strict current-v4.27 recruitment and replication, the miniF2F/PutnamBench confirmation, and the oracle-assisted known-solvable multi-step design.
- [Supplementary results](supplementary_results.md): complete supporting measurements, the seven-view by three-canonicalizer sensitivity matrix, terminal/nonterminal decomposition, Supplementary Figure S1, archived protocol decisions, process- and tactic-call savings, multi-step solve coverage, the consolidated scope and exception ledger in Section S18, and all 32 strict-frame repository rates in Section S20.
- [Worked example](worked_example.md): one theorem-level live state and two independent branches.
- [Cross-head pair frequencies](exp48_pair_frequencies.md): all 71 archived cross-head pairs from the untouched confirmation study.
- [Literature-gap matrix](literature_gap_matrix.md): closest-neighbor question-by-question comparison.
- [Claim-to-evidence table](claim_to_evidence_table.md): formal, empirical, reproducibility, and intervention claims with explicit boundaries.
- [Artifact manifest](artifact_manifest.md): local bundle identities and roles.
- [Reproduction order](reproduction_order.md): archive-first verification sequence.
- [Figure provenance](figure_plan.md): current main-text figure roles and export checks.

The source experiment bundles, not these prose summaries, are authoritative for numerical values.
