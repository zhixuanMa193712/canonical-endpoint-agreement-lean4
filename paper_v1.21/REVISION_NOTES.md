# v1.21 修改说明（2026-09-18）

本轮依据两份内部评估，对 v1.20 正文与补充材料修订。不新增 Lean 实验；原稿与原始 ZIP 不覆盖。新版的外部实验数值来自公开标注的事后离线解析更正，不能继续引用旧审计作为更正结果的验证。

## 实质性发现与处理

检查 M8 所指 head 提取规则时，发现外部实验 `tactic_head` 的正则表达式过度转义，把字母 s 当作分隔符。例如 simp/simpa/simp_all/solve_by_elim 被映射到 `<empty>`，aesop/aesop? 同为 ae。旧审计可以复现这个错误，不能识别规则本身错误。

`reanalyze_heads.py` 从两个原始 ZIP 的科学执行回执读取完整 tactic 文本和 structural endpoint 哈希，先逐根重建旧 Y 指标并核对归档分析，再更正 head 与 family；另用直接两两配对谓词交叉核对端点分组实现。没有修改 candidate、顺序、执行结果、端点或根样本，也没有重新运行 Lean。只纳入 scientific 回执，排除 smoke 回执。

## 表达与结果安排

使用论文润色流程，以替换、合并为主；主文保留候选相对频率、多步收益及解释范围。源文件聚类、逐根分布和解析更正细节进入补充材料。术语统一为 lexical head（词法提取）、candidate-relative frequency（候选集相对频率）、descriptive frame-resampling interval（描述性框架重抽样区间）。原始实验档案保留。

Figure 4 的 matplotlib 绘图源采用项目已有 Python 工作流。静态检查的幅宽警告来自通用 Nature 尺寸，不适用于当前 Springer 正文幅宽；PNG 仅用于预览，正文嵌入矢量 PDF，因此不提交 TIFF。图中文字与几何碰撞检查必须通过；全文与补充材料另做逐页视觉检查。

## 复算

在项目根目录用具有 NumPy 的 Python 执行 `python paper_v1.21/reanalyze_heads.py`。输入为项目根目录两个原始外部结果 ZIP 和多步结果 ZIP；标签分组常量读取现有协议源。输出在本目录 `analysis/`。更正层与原始 ZIP 必须一同保存；不要替换原始 ZIP 中的旧回执。
